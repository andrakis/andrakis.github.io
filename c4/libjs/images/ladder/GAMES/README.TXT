FULL GAMES (UPLOADS): playing the full games with your own files

The games in the Full Games (Uploads) group play the full, registered
versions, from game files you own. This disk does not have them: you
add them to the page, and C4DOS finds them on A:.

ADDING YOUR FILES

1. Click Uploads, at the top of the page.
2. In "Put new files in", pick the game's folder (for Duke Nukem 3D,
   /home/duke3d).
3. Click Add files..., and pick the game's files (or drop them on the
   page). The dialog's "What the games need" list ticks each one it
   has.
4. Click Boot with them.

Under C4DOS the files are then on A:, beside the disk's own files, in
the game's folder: A:\DUKE3D\DUKE3D.GRP. They are kept in the browser,
not on the disk, and Forget in the Uploads dialog takes them away.
While a file is uploaded, it hides a file of the same name on A:.

WHAT EACH GAME NEEDS

Wolfenstein 3D (registered)
    Needs: AUDIOHED.WL6, AUDIOT.WL6, GAMEMAPS.WL6, MAPHEAD.WL6,
    VGADICT.WL6, VGAGRAPH.WL6, VGAHEAD.WL6, VSWAP.WL6
    In: A:\WOLF3D (the Uploads folder /home/wolf3d)
    Start: grin, Full Games (Uploads) > Wolfenstein 3D, or
    \GAMES\WOLF3D\WOLF3D6

Doom (The Ultimate Doom, Doom II, Final Doom)
    Needs one of: DOOM.WAD, DOOM2.WAD, TNT.WAD, PLUTONIA.WAD
    In: A:\DOOM (the Uploads folder /home/doom)
    Start: grin, Full Games (Uploads) > The Ultimate Doom, Doom II,
    TNT, Plutonia, or \GAMES\DOOM\DOOM -home

Duke Nukem 3D (1.3D, 1.4, Atomic 1.5)
    Needs: DUKE3D.GRP
    In: A:\DUKE3D (the Uploads folder /home/duke3d)
    Start: grin, Full Games (Uploads) > Duke Nukem 3D, or
    \GAMES\DUKE3D\DUKE3D -home

Quake (registered)
    Needs: PAK1.PAK
    Also, if you have it: PAK0.PAK
    In: A:\QUAKE (the Uploads folder /home/quake)
    Start: grin, Full Games (Uploads) > Quake, or \GAMES\QUAKE\QUAKE
    -home

Rise of the Triad (registered)
    Needs: DARKWAR.WAD, DARKWAR.RTL, DARKWAR.RTC
    Also, if you have it: REMOTE1.RTS
    In: A:\ROTT (the Uploads folder /home/rott)
    Start: grin, Full Games (Uploads) > Rise of the Triad, or
    \GAMES\ROTT\ROTTREG

A game started without its files says which it wants, and stops.
